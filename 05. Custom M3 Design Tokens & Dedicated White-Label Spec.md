# Custom M3 Design Tokens & Dedicated White-Label Spec

**Proyek:** Redesign & Re-Architecture Master Platform Digibi (Dedicated White-Label Factory)  

**Tentang Dokumen:** Menghapus opsi kustomisasi *border-radius* dari pengaturan klien (menguncinya sebagai standar baku *master design system* agar geometri UI selalu rapi) dan memastikan opsi pemilihan **Font Heading** serta **Font Body** dari Google Fonts tersedia di Web Dashboard.

## 2. Arsitektur 3 Lapis Design Token

1. **Layer 1 — Primitive / Core Tokens (Statis & Dikunci Master):**  
   Mencakup skala warna netral (*slate*), skala *spacing* kelipatan `4px / 4dp`, skala ukuran huruf Material 3, serta **standar geometri sudut (*shape tokens*)** yang dikunci seragam untuk semua klien:
   * Kartu (*Card Surface*): `16px` / `16.dp`
   * Tombol (*CTA Button*): `12px` / `12.dp`
   * Wadah Ikon Menu (*Squircle Icon Container*): `14px` / `14.dp`
   * Input Field: `12px` / `12.dp`
2. **Layer 2 — White-Label Semantic Tokens (Dinamis dari Database):**  
   Token warna utama, permukaan, serta pasangan **Font Heading & Font Body** yang nilainya diatur di *White-Label Provisioning Studio* dan di-override otomatis oleh JSON `/api/v1/tenant/bootstrap`.
3. **Layer 3 — Domain Component Tokens (Turunan Otomatis):**  
   Token spesifik untuk komponen khas Digibi (kartu saldo ganda, latar ikon SVG `Primary 10%`, badge status tagihan) yang diturunkan otomatis dari Layer 2.

## 4. Dynamic Typography Tokens (Curated Google Fonts)

Di *White-Label Provisioning Studio* pada Web Dashboard, admin memiliki **2 dropdown terpisah** untuk mengatur **Font Heading** dan **Font Body** masing-masing klien. Seluruh font diambil dari **Google Fonts** berlisensi *SIL Open Font License (OFL)* / *Apache 2.0* yang gratis untuk produk komersial, dan dimuat secara *runtime* lewat tag `<link>` di Angular serta *Jetpack Compose Downloadable Fonts* (`ui-text-google-fonts`) di Kotlin tanpa membundel file `.ttf`.

### 4.3 Aturan Tabular Numbers untuk Nominal Keuangan
Setiap komponen yang menampilkan angka uang (`Rp 90.000`, `Grand Total`, tabel mutasi) wajib mengaktifkan fitur *tabular figures* agar lebar tiap digit seragam dan tidak bergeser saat angka berubah:
* **Angular (CSS):** `font-variant-numeric: tabular-nums;`
* **Kotlin Compose:** `fontFeatureSettings = "tnum"`

## 5. Aturan Auto-Contrast (WCAG AA Protection)

Saat tim Digibi atau admin klien memilih warna `brandPrimary` di *White-Label Configurator*, front-end wajib menghitung tingkat kecerahan (*relative luminance* $L$) sebelum menetapkan warna teks `onBrandPrimary`:

$$L = 0.2126 \times R + 0.7152 \times G + 0.0722 \times B$$

* Jika $L > 0.55$ (klien memakai warna utama terang seperti kuning atau hijau muda), sistem otomatis menetapkan `onBrandPrimary = #0F172A` (gelap).
* Jika $L \le 0.55$ (klien memakai warna utama gelap seperti maroon, navy, atau hijau tua), sistem menetapkan `onBrandPrimary = #FFFFFF` (putih).

## 6. Spesifikasi Teknis Logo & Ikon Menu Utama (SVG Format)

1. **Logo Klien (`logoLightUrl` & `logoDarkUrl`):**
   * Format `.svg` transparan dengan tinggi kanvas standar `32px`.
   * Untuk Android, logo *splash screen* ikut dibundel pada direktori `src/<flavor>/res/` masing-masing klien agar tampil instan saat aplikasi pertama kali dibuka (*cold start*).
2. **Ikon Menu Utama (`tenant_menus`):**
   * Wajib berformat `.svg` dengan `viewBox="0 0 24 24"` dan area aman (*safe zone*) `20x20` di tengah.
   * Dilarang menyematkan tag `<image>` (bitmap di dalam SVG) atau tag `<style>` eksternal agar parser Android Vector/Coil berjalan mulus.
   * **Dua Mode Rendering:**
     * `tinted`: SVG dibuat monokrom (`fill="currentColor"` atau `#000000`) sehingga Angular dan Kotlin otomatis mewarnai path-nya menggunakan token `iconTint` klien.
     * `multicolor`: SVG mempertahankan palet ilustrasi multi-warna khusus yang dirancang untuk klien tersebut.
