# Custom M3 Design Tokens & Dedicated White-Label Spec

**Proyek:** Redesign & Re-Architecture Master Platform Digibi (Dedicated White-Label Factory)  

**Tujuan Dokumen:** Memisahkan konfigurasi **Build-Time Identity** (identitas paket/domain khusus klien saat *deal*) dan **Runtime Design Tokens** (warna tema, logo, dan ikon SVG menu dari database) agar tim tidak perlu lagi mengedit kode warna/ikon secara manual per klien.

---

```text
[1 MASTER CODEBASE (Angular Terbaru & Kotlin Compose)]

       │

             • Menyuntikkan primaryColor, secondaryColor, radius, & logo SVG
             • Memuat daftar ikon menu SVG (mode tinted / multicolor)
             • Dapat diubah kapan saja lewat Web Configurator tanpa rebuild app
```

## 2. Arsitektur 3 Lapis Design Token

1. **Layer 1 — Primitive / Core Tokens (Statis):** Skala warna netral (*slate*), skala *spacing* kelipatan `4px / 4dp`, dan hierarki tipografi Material 3. Dikunci oleh *master template*.
2. **Layer 2 — White-Label Semantic Tokens (Dinamis dari Database):** Token warna utama, permukaan, dan kelengkungan sudut yang nilainya di-override oleh JSON `/api/v1/tenant/bootstrap` milik klien tersebut.
3. **Layer 3 — Domain Component Tokens (Turunan Otomatis):** Token spesifik untuk komponen khas Digibi (kartu saldo ganda, latar ikon SVG, badge status tagihan) yang diturunkan otomatis dari Layer 2.

## 4. Aturan Auto-Contrast (WCAG AA Protection)

Saat tim Digibi atau admin klien memilih warna `brandPrimary` di *White-Label Configurator*, front-end wajib menghitung tingkat kecerahan (*relative luminance* $L$) sebelum menetapkan warna teks `onBrandPrimary`:

$$L = 0.2126 \times R + 0.7152 \times G + 0.0722 \times B$$

* Jika $L > 0.55$ (klien memakai warna utama terang seperti kuning atau hijau muda), sistem otomatis menetapkan `onBrandPrimary = #0F172A` (gelap).
* Jika $L \le 0.55$ (klien memakai warna utama gelap seperti maroon, navy, atau hijau tua), sistem menetapkan `onBrandPrimary = #FFFFFF` (putih).

## 5. Spesifikasi Teknis Logo & Ikon Menu Utama (SVG Format)

1. **Logo Klien (`logoLightUrl` & `logoDarkUrl`):**
   * Format `.svg` transparan dengan tinggi kanvas standar `32px`.
   * Untuk Android, logo *splash screen* ikut dibundel pada direktori `src/<flavor>/res/` masing-masing klien agar tampil instan saat aplikasi pertama kali dibuka (*cold start*).
2. **Ikon Menu Utama (`tenant_menus`):**
   * Wajib berformat `.svg` dengan `viewBox="0 0 24 24"` dan area aman (*safe zone*) `20x20` di tengah.
   * Dilarang menyematkan tag `<image>` (bitmap di dalam SVG) atau tag `<style>` eksternal agar parser Android Vector/Coil berjalan mulus.
   * **Dua Mode Rendering:**
     * `tinted`: SVG dibuat monokrom (`fill="currentColor"` atau `#000000`) sehingga Angular dan Kotlin otomatis mewarnai path-nya menggunakan token `iconTint` klien.
     * `multicolor`: SVG mempertahankan palet ilustrasi multi-warna khusus yang dirancang untuk klien tersebut.
