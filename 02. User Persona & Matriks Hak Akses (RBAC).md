# User Persona & Matriks Hak Akses (RBAC)

**Proyek:** Redesign & Re-Architecture Master Platform Digibi (White-Label Ecosystem)  
**Tujuan Dokumen:** Menetapkan batasan antarmuka berdasarkan peran pengguna (*Role-Based Access Control*) agar fitur administratif/kasir tidak bocor ke tampilan anggota biasa, sekaligus menentukan prioritas gelombang pengembangan (*Wave Development*).

---

## 1. Pemetaan 5 Persona Utama Ekosistem Digibi

Karena Digibi bersifat *multi-tenant* (digunakan oleh organisasi masyarakat seperti DMI, koperasi simpan-pinjam, pesantren, dan sekolah), pengguna dibagi menjadi 5 persona inti:

| Kode Role (Database) | Nama Persona | Platform Utama | Karakteristik & Kebutuhan Utama |
| :--- | :--- | :--- | :--- |
| `SUPER_ADMIN` | **Platform Owner (Digibi)** | Web Dashboard | Mengelola pendaftaran klien (*tenant*) baru, mengaktifkan/menonaktifkan modul per klien, serta memantau kesehatan sistem lintas *tenant*. |
| `TENANT_ADMIN` | **Pengurus Koperasi / Admin Yayasan** | Web Dashboard | Mengatur identitas *white-label* (warna tema, logo, ikon SVG menu), memverifikasi anggota, menyetujui pembiayaan/cicilan, mengelola stok `Mart`, dan memantau laporan keuangan. |
| `FIELD_OFFICER` | **Petugas Lapangan / Kasir / Panitia** | Mobile App (Mode Petugas) | Melayani transaksi tunai/kantin (`Admin Blanja&Tunai`), memindai QR Code kehadiran peserta acara (`Absen Member`), dan memvalidasi pengambilan barang. |
| `MEMBER` | **Anggota Koperasi / Jamaah Umum** | Mobile App | Mengelola saldo `Dompet` & `Simpanan`, mengajukan pembiayaan cicilan, berbelanja di `Mart`, membayar tagihan `PPOB`, berdonasi `ZISWAF`, serta mendaftar `Umrah/Haji` & `Acara`. |
| `GUARDIAN` | **Wali Santri / Orang Tua Siswa** | Mobile App | Memantau tagihan dan membayar `SPP Santri`, mengisi saldo uang jajan *cashless* sekolah, serta mengunduh dokumen pengumuman yayasan (`Shared Docs`). |

## 2. Matriks Hak Akses Modul (RBAC Matrix)

**Keterangan Izin:**  
* `C` = Create (Tambah/Ajukan)  
* `R` = Read (Lihat)  
* `U` = Update (Ubah)  
* `D` = Delete (Hapus)  
* `APR` = Approve / Otorisasi / Scan Validasi  
* `-` = Tidak Memiliki Akses (Menu disembunyikan total dari UI)

| **White-Label Branding & SVG Menu** | `C R U D` | `R U` | `-` | `-` | `-` |

## 3. Aturan Implementasi RBAC di Front-End (Angular & Kotlin)

Untuk mencegah masalah lama (seperti munculnya menu `Admin Blanja&Tunai` di layar anggota biasa), front-end wajib menerapkan **Two-Layer Filtering**:

1. **Layer 1 — Tenant Module Activation (`enabledModules`):**  
   Jika klien adalah koperasi non-sekolah, modul `CASHLESS_SCHOOL` tidak dikirim oleh server, sehingga menu `SPP Santri` tidak dirender di Web maupun Mobile.
2. **Layer 2 — User Role Intersection (`allowedRoles`):**  
   Setiap item menu di JSON `/tenant/bootstrap` membawa array `allowedRoles`. Front-end melakukan pencocokan dengan `user.roles` saat login:
   * Jika user hanya memiliki role `["MEMBER"]`, menu dengan `allowedRoles: ["FIELD_OFFICER"]` otomatis disaring (*filtered out*) sebelum komponen UI dirender.
   * Jika user memiliki multi-role `["MEMBER", "FIELD_OFFICER"]`, Mobile App menyediakan **Role Switcher Pill** di bagian atas Beranda untuk berpindah antara *Mode Anggota* dan *Mode Petugas/Kasir*.

## 4. Peta Prioritas Gelombang Development (Wave Strategy)

Berdasarkan ketergantungan data antara Web Dashboard (sebagai dapur konfigurasi) dan Mobile App, pengembangan **Tahap 3** dibagi menjadi 3 gelombang:

* **Gelombang 1 — Web Dashboard Core & White-Label Configurator (Angular):**
  * Autentikasi, RBAC Guard, & Layout Modular.
  * Halaman **Theme & SVG Menu Studio** (mengatur hex token M3, upload logo light/dark, upload ikon SVG menu utama, dan preview langsung).
  * CRUD Data Master untuk mendukung Mobile MVP (Anggota, Produk Mart, Kampanye ZISWAF, Daftar Acara, Shared Docs, & Produk Cicilan).
* **Gelombang 2 — Android Kotlin Native MVP (Jetpack Compose):**
  * Dynamic Theme Engine (`MaterialTheme` + `CompositionLocal` dari API bootstrap) & Coil 3 SVG Loader.
  * Layar Utama & Transaksi Inti: Beranda (Dual Wallet + 4-Column SVG Grid), Mart, PPOB, ZISWAF, Daftar Acara (QR Ticket), Shared Docs, dan Simulasi Product Cicilan dengan animasi *Shared Element* & *Spring*.
* **Gelombang 3 — Web Dashboard Advanced Analytics & Multi-Layer Finance (Angular):**
  * Grafik arus kas simpan-pinjam, manajemen aset & karyawan, serta otorisasi keuangan multi-layer pengurus koperasi.
