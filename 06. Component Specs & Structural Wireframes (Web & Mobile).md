## 3. Spesifikasi Animasi Kotlin Jetpack Compose

1. **Shared Element Transition (`SharedTransitionLayout`):** Ikon SVG di grid Beranda bertransformasi mulus menjadi ikon *header* saat masuk ke layar modul (`ZISWAF`, `Events`, `PPOB`, `Dues`).
2. **Spring Digit Roll (`AnimatedContent`):** Digunakan pada kartu saldo `Dompet`/`Simpanan` saat *pull-to-refresh* dan pada angka `Estimasi Angsuran` di layar *Product Cicilan* saat pengguna mengganti tenor atau jumlah order.
3. **Digital ID Card Flip (`graphicsLayer`):** Kartu anggota digital dapat diketuk untuk berputar $180^{\circ}$ secara horizontal menampilkan detail keanggotaan di sisi depan dan QR Code beresolusi tinggi di sisi belakang.
